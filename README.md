# nextpad.github.io

Project site of [NextPad](https://github.com/christiansteier/NextPad), built with [Zola](https://www.getzola.org) 0.23.6.

The source of truth is `site/` in the NextPad repository; this repository receives a copy on every export. Changes belong there.

```bash
zola serve    # local preview on http://127.0.0.1:1111
```
